Coding

The activity of designing and writing programs to instruct a computer to complete a series of tasks

About Coding

The origin of code

Humans have been using various devices in order to aid computation for thousands of years. However, the digital computers we know of today would not come about until the late 1900s. Computers back then were big and bulky, only existing in carefully maintained labs with professionals tending to them 24/7. Code was manually configured by moving physical switches, or with long strings of punch cards.


Ease of coding today

Nowadays, with the advent of the digital era, most people have at least 1 device on them. Even your microwave has more computational power than the first computers! With such easy access to computers, and advancements in coding languages, coding is now something that is accessible to virtually everyone.

Low-level Abstraction

Low-level languages are very close to the computer's hardware. They provide little abstraction, meaning you control exactly what the CPU and memory are doing.

Mid-level Abstraction

Mid-level languages bridge the gap between hardware and high-level programming. They provide higher-level constructs while still allowing direct access to memory and hardware when needed.

High-level Abstraction

High-level languages are designed to be easy for humans to read and write. They hide most of the complexity of the hardware.

Choosing a Programming Language

What language you want to use depends on the exact goal you want to achieve. For example, JavaScript is for Web Development, Python is for Data Analytics, C is for Middleware like Game Engines and etc.

Different Languages for Full-Stack Development

Some programs, like Web Apps, require multiple technologies in order to function. For example, the browser could be coded in C#, while the webpage is done in HTML/CSS/JS. At the server's end, it could use PHP and Python to process the recieved data.

Low-level vs High-level

Low-level languages allow you to interact with computer hardware directly, but require much more skill and expertise because of this management. High-level languages automatically configure these things for the programmer, allowing them to focus on the actual scripting logic.

Issues with High-level

High-level codes will always be less efficent than Low-level codes due to things like memory management and CPU controllers. However, some people argue that this difference is marginal as most programmers are not skilled enough to properly make that difference.
